# TROVA INMOBILIARIA

Repositorio de automatizaciones de Trova Inmobiliaria.

## Contenido

- [`integrations/odoo-easybroker-sync/`](integrations/odoo-easybroker-sync/README.md) — sincroniza viviendas capturadas en Odoo hacia EasyBroker, que a su vez las publica automáticamente en Inmuebles24, Vivanuncios, Lamudi, Propiedades.com y demás portales conectados a la cuenta de EasyBroker. Corre como un workflow programado de GitHub Actions (`.github/workflows/sync-viviendas.yml`).
